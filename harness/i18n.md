# i18n 규칙

## 지원 언어

- 기본 언어: `ko`
- 지원 언어: `ko`, `en`

## 규칙

- 사용자가 보는 문구가 공용 문구이거나 페이지 단위 문구라면 `src/i18n/dictionaries.ts`에서 가져온다.
- 한국어 문구를 기준 원본으로 삼는다.
- 같은 key에 대해 영어 문구도 함께 유지한다.
- 프로젝트 데이터의 다국어 필드는 `src/i18n/dictionaries.ts`에 둘 수 있다.
- 임시 문구가 아니라면 페이지 컴포넌트에 제목, 라벨, 설명 문구를 하드코딩하지 않는다.
- 웹 페이지 문구와 슬라이드 문구는 같은 내용을 보완할 수 있지만, 서로의 표시 목적과 레이아웃을 위해 별도 콘텐츠로 관리한다.
- 슬라이드 전용 문구는 `src/i18n/slide-content.ts`, 업무·프로젝트 발표용 원문은 `src/i18n/professional-content.ts`와 `src/i18n/pdf-architecture-content.ts`에서 관리한다.
- 슬라이드 콘텐츠를 웹 페이지의 기존 사전 값에 덮어쓰거나 웹 페이지의 정렬·요약 데이터를 변환하지 않는다.

## 현재 범위

현재 프로젝트는 정적 기본 언어 헬퍼를 사용한다. 언어별 라우팅은 나중에 다음 형태로 추가할 수 있다.

```text
/ko
/en
```

언어별 라우팅을 추가하기 전까지는 한국어 사전을 기본으로 렌더링한다.
